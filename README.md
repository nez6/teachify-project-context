# Teachify project context

Read the full page: open `index.html` through this repository's GitHub Pages site.

Teachify reads handwritten math through a phone or desk camera, finds the exact line where a student went wrong, and gives a hint instead of the answer.

- Live app: https://teachify-483454783485.us-central1.run.app
- `index.html`: the product, pitch, architecture, results, setup, status, risks and full source
- `teachify-source.zip`: runnable source code, including 3D models and firmware
