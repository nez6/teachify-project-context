How this Teachify is built

Teachify finds the first line where a student's math goes wrong and gives a hint instead of the answer. This build keeps every original part and adds Pip: a buddy you can talk to, who does things for you.

Original project: project page and repository. This version lives on the buddy branch.

Keys and safety

Every API key lives only in the hosting platform's environment. None is in the repository. The browser sees only Vapi's public key, which is designed to be public. Pip's tools call the same checker as the student app, and the hint rules (never the answer) are in both the prompt and the tool result.

Like the original, this is a demo: class state is in memory, names are synthetic, and a real school pilot still needs logins, a database, and a FERPA and COPPA review.
