The short version

The problem

A wrong final answer hides where the mistake began. Students stay quiet, teachers have no spare hours, and nobody can watch every line.

The product

A camera watches the page. Teachify checks each step against the one above, flags the first bad line, and gives a hint. Teachers see who is stuck, why, and what to ask.

Why it can be trusted

A fine-tuned handwriting reader was tested on held-out data, and a symbolic math engine checks the algebra instead of trusting AI alone.

Target: Algebra 1, Algebra 2, Pre-Calc and Calculus, in middle and high school. Built for a hackathon using Google Cloud, Thinking Machines' Tinker and an Entrinsik Informer challenge.

The core idea

AI does not decide whether typed or transcribed math is correct. For an equation problem, a line is valid if it has the same solution set as the problem, so the first error is the smallest k where S(L_k) != S(P). Derivative problems compare each line with f'(x). A valid alternate method is therefore not marked wrong.

Safety decisions

  • SymPy's parser uses eval, so input passes a strict whitelist first. Exponents are capped, chained powers are rejected, and lines and line counts are limited.
  • Only parsed math goes to the wording models; names and free text do not.
  • Provider failures log only the exception class.
  • Reporting uses seat numbers, not names, and includes a simulated column.

Limits of the design

  • Class state is in memory, so restarting clears it and the service must run as one instance.
  • The student roster is fake and there are no logins.
  • Rules cover four problem types: distribution, moving terms, factoring and derivatives. Pre-Calc is marketing scope, not built.

Statistics plan

H0: fine-tuning does not change reading accuracy. H1: it does. Because models read the same images, the right test is McNemar's exact test; several models need Cochran's Q plus corrected pairwise tests. The published intervals for the LoRA and base model do not overlap, but the paired p-value still has to be calculated from the raw predictions.

Test sizeSmallest detectable gainApproximate 95% CI at 80% accuracy
1,000 lines3.4 points±2.5 points
500 lines4.8 points±3.5 points
100 questions10.7 points±7.8 points
100 questions across 5 models, Bonferroni13.9 points±7.8 points

Assumes 80% power, alpha 0.05 and 15% disagreement. A 24.5-point gain means at least 24.5% of lines disagreed, so 15% is too low for this pair. At 30% disagreement, 1,000 lines still detects roughly 5 points, and the observed gain is far larger. Recalculate from raw predictions.

The original plan mentioned 1,500 test items, with 1,000 public and 500 uploaded documents. Published results cover only the 1,000 HME100K lines. The 100-question benchmark can rank cost, but cannot separate close models on accuracy.

# Teachify

Catches the exact line where a student's math goes wrong, then tells the teacher who needs help and what to ask.

- **Student app** (`/student`): step-by-step work, a nudge that doesn't give the answer, XP for fixing your own mistake.
- **System A, error detection** (`app/detector.py`): SymPy finds the first invalid line and matches it to a known misconception.
- **System B, teacher brief** (`app/ai.py`, `/teacher`): Thinking Machines or Gemini words the advice. It can't change the math verdict.
- **Desk tripod** (`/node`, `hardware/`): holds a phone or camera over the student's paper, with a status light and a live 3D twin.

## What it does

It's 11:40 pm and Prince is on problem 7. He knows his answer is wrong. He doesn't know which line.

Going through math problems is hard, and as a past tutor, we want our kids to have the best chance of success. We loved tutoring, but there was only one of us to go around.

Teachers can't close that gap alone. They average 53 hours a week, against 44 for similar working adults (RAND 2024). Asking for help is hard too: about 40% of high schoolers regularly hesitate to admit they're confused (Character Lab Research Network, 1,000+ students).

Teachify finds the first line that went wrong and gives a hint, never the answer. It covers Algebra 1 and 2, Pre-Calc and Calculus, for middle and high school. Take this work:

$$
3(x+2) = 2x + 11 \quad\Rightarrow\quad 3x + 2 = 2x + 11 \quad\Rightarrow\quad x = 9
$$

The correct answer is \\(x = 5\\). Only the first step is wrong, and everything after it follows correctly. The tutor points at that step and stops there:

> "Look at your first step. What does the 3 multiply?"

We have one product for home and three for school:

- **Personal Tutor:** at home, a student takes a phone photo of their work and gets a hint, not the answer.
- **Enterprise A, Detect:** a desk camera watches the work, and a light turns on when a step is wrong.
- **Enterprise B, Assist:** an AI helper talks to the student over headphones.
- **Enterprise C, Quiet mode:** Teachify auto-grades the work and sends flagged lines back to the student.

About 77% of public schools ban phones in class (NCES), so the classroom products use a desk camera.

## How we built it

The app runs five steps:

1. The camera takes a photo of the work.
2. Gemini reads each line.
3. Gemini judges each line against the line above.
4. SymPy re-checks each algebra step.
5. The student gets a hint only when Gemini and SymPy agree, and never the answer.

For an equation problem \\(P\\), each line should keep the same solution set, so the first error is:

$$
k^{\ast} = \min \lbrace k : S(L_k) \neq S(P) \rbrace
$$

In the example, \\(S(P) = \lbrace 5 \rbrace\\) but the first step has solution set \\(\lbrace 9 \rbrace\\), so \\(k^{\ast} = 1\\).

We also fine-tuned our own handwriting reader: Qwen3.5-4B with a rank-16 LoRA, trained on Thinking Machines' Tinker. One epoch over 20,016 handwritten lines took 2 h 9 min and cost $1.88. The fine-tuned reader isn't wired into the live app yet.

The app is built for Google Cloud Run. Entrinsik Informer is the reporting layer, fed by a token-protected, read-only REST feed that uses seat numbers rather than names. A 3D-printed tripod holds a phone or a XIAO ESP32S3 Sense camera about 30 cm above the page, with swappable 1/4"-20 mounts and a status light. We used Claude Code to help build.

## Challenges we ran into

- **One mistake can look like many.** After the wrong step in our example, \\(x = 9\\) is correct for the line above it. Whole-page grading marks those later lines wrong anyway, so we judge each line against the one above.
- **Handwritten math is hard to read.** Even the best hosted model we tested read fewer than 6 in 10 lines exactly.
- **Phones are banned in most classrooms.** That pushed us to a desk camera and a tripod that holds it above the page.
- **A fair comparison is hard.** Our reader was trained on the same dataset's conventions as the test set, so its lead over hosted models is an upper bound.

## Accomplishments that we're proud of

Our fine-tuned reader scored highest of the models we tested on 1,000 held-out HME100K line crops, by exact match after normalisation (Wilson 95% CI where shown):

- **Qwen3.5-4B + LoRA:** 76.5% [73.8, 79.0]
- **Gemini 3.6 Flash:** 57.9% [54.8, 60.9]
- **Qwen3.5-4B base:** 52.0% [48.9, 55.1]
- **Gemini 3.5 Flash-lite:** 51.1%
- **Claude Sonnet 5.5:** 49.1%

Because of the shared dataset conventions, treat the gap over hosted models as an upper bound.

On 29 labelled images, step-by-step judging left every valid line after a mistake unflagged (18 of 18). Whole-page grading flagged them all (0 of 18 left unflagged).

def _normalize(raw: str) -> str:
    text = raw.strip().lower()
    for old, new in (("−", "-"), ("–", "-"), ("×", "*"), ("·", "*"), ("²", "^2"), ("³", "^3")):
        text = text.replace(old, new)

def parse_side(text: str):
    """Parse one math expression. Rejects anything outside the whitelist."""
    text = text.strip()
    if not text or len(text) > MAX_LINE or not _SAFE.match(text) or "**" in text:
        raise Unreadable(text)
    for match in re.finditer(r"\^\s*(\S?)", text):
        if not match.group(1).isdigit():
            raise Unreadable(text)
    for exponent in re.findall(r"\^\s*(\d+)", text):
        if int(exponent) > MAX_EXPONENT:
            raise Unreadable(text)
    if re.search(r"\^\s*\d+\s*\^", text):
        raise Unreadable(text)
    try:
        value = parse_expr(text, transformations=_TRANSFORMS, local_dict={"x": x})
    except Exception as exc:
        raise Unreadable(text) from exc
    if not hasattr(value, "has") or value.has(zoo, nan, oo, -oo):
        raise Unreadable(text)
    return value


def _degree_ok(expr) -> bool:

def solution_set(line: str):
    """Return (set_of_roots, difference_expr, branches). 'ALL' means every x works."""
    parts = [p for p in re.split(r"\bor\b|,", line) if p.strip()]
    roots = set()
    diffs = []
    for part in parts:
        if part.count("=") != 1:
            raise Unreadable(line)
        left, right = part.split("=")
        difference = expand(parse_side(left) - parse_side(right))
        if difference.has(zoo, nan) or not _degree_ok(difference):
            raise Unreadable(line)
        diffs.append(difference)
        if difference == 0:
            return "ALL", difference, diffs
        roots.update(solve(difference, x))
    return roots, diffs[0], diffs


def _proportional(a, b) -> bool:
    if b == 0 or a == 0:
        return a == b
    ratio = simplify(a / b)
    return ratio.is_number is True and ratio != 0


def _terms(line: str) -> List:
    left, right = line.split("=")
    return list(Add.make_args(expand(parse_side(left)))) + [
        -t for t in Add.make_args(expand(parse_side(right)))

def _classify_equation(prev: str, cur: str) -> str:
    try:
        cur_roots, cur_diff, cur_branches = solution_set(cur)
        prev_roots, prev_diff, prev_branches = solution_set(prev)
    except Unreadable:
        return "other_slip"

    # Partial distribution needs the raw text: SymPy auto-distributes 3*(x+2).
    pattern = r"(-?\d+)\s*\*?\s*\(\s*x\s*([+-])\s*(\d+)\s*\)"
    if re.search(pattern, prev) and "=" in prev:
        partial = re.sub(pattern, lambda m: f"({m.group(1)}x{m.group(2)}{m.group(3)})", prev)
        left, right = partial.split("=")
        if _proportional(cur_diff, expand(parse_side(left) - parse_side(right))):
            return "partial_distribution"

    if len(prev_branches) == 1 and "=" in prev:
        if prev_diff.coeff(x, 2) != 0 and cur_diff.coeff(x, 2) != 0:
            scale = cur_diff.coeff(x, 2) / prev_diff.coeff(x, 2)
            if (
                cur_diff.coeff(x, 1) == -scale * prev_diff.coeff(x, 1)
                and cur_diff.coeff(x, 0) == scale * prev_diff.coeff(x, 0)
            ):
                return "factor_sign"

        terms = _terms(prev)
        for term in terms:
            if _proportional(cur_diff, expand(prev_diff - 2 * term)):
                return "sign_on_move"

        coefficient = prev_diff.coeff(x, 1)
        if prev_diff.coeff(x, 2) == 0 and coefficient not in (S.Zero, S.One, S.NegativeOne):
            x_term = coefficient * x
            others = [t for t in terms if t.has(x) is False]
            only_x = expand(x_term / coefficient + sum(others))
            if _proportional(cur_diff, only_x):
                return "partial_division"
            for kept in others:
                candidate = expand((prev_diff - kept) / coefficient + kept)
                if _proportional(cur_diff, candidate):
                    return "partial_division"

            constant = -prev_diff.coeff(x, 0)
            if isinstance(cur_roots, set) and len(cur_roots) == 1:
                root = next(iter(cur_roots))
                wrong = {constant * coefficient, constant - coefficient, constant + coefficient}
                if constant != 0:
                    wrong.add(coefficient / constant)
                if root in wrong:
                    return "inverse_operation"

    if isinstance(cur_roots, set) and isinstance(prev_roots, set) and cur_roots:
        if {-r for r in prev_roots} == cur_roots:
            return "zero_product_sign"
    return "other_slip"


def _classify_derivative(f, expected, cur) -> str:
    terms = Add.make_args(expand(f))
    no_reduce = no_multiply = S.Zero
    for term in terms:
        coefficient, power = term.as_coeff_exponent(x)
        if power == 0:
            continue
        no_reduce += coefficient * power * x ** power
        no_multiply += coefficient * x ** (power - 1)
    cur = expand(cur)
    constant = expand(f).coeff(x, 0)
    # A student can stop the rule at x^1 correctly and still be on this pattern,
    # so compare only the terms with degree above one.
    if cur == expand(no_reduce):
        return "power_rule_no_reduce"
    if cur.coeff(x, 3) == no_reduce.coeff(x, 3) and cur.coeff(x, 3) != 0:
        return "power_rule_no_reduce"
    if cur == expand(no_multiply):
        return "power_rule_no_multiply"
    if constant != 0 and cur == expand(expected + constant):
        return "constant_kept"
    return "other_slip"

async def handle_attempt(body: Attempt, simulated: bool = False) -> dict:
    student = get_student(body.student_id)
    problem = PROBLEMS.get(body.problem_id)
    if not problem:
        raise HTTPException(404, "Unknown problem")

    result = await run_in_threadpool(analyze, body.problem_id, body.lines)
    student["simulated"] = simulated
    previous = student["last_attempt"].get(body.problem_id)
    student["last_attempt"][body.problem_id] = result["verdict"]
    existing = open_alert_for(student["id"])
    reward = None

    if result["verdict"] == "error":
        student["status"] = "stuck"
        student["streak"] = 0
        if existing and existing["problem"] == problem["text"]:
            help_requested = existing["help_requested"]
            source = existing["source"]
            status = existing["status"]
            del state["alerts"][existing["id"]]
            alert = new_alert(student, problem, result, "error", source)
            alert["help_requested"], alert["status"] = help_requested, status
        else:
            alert = new_alert(student, problem, result, "error", "app")
        asyncio.ensure_future(improve_brief(alert))
    elif result["verdict"] == "correct":
        comeback = previous == "error"
        points = 25 if comeback else 10
        student["xp"] += points
        student["streak"] += 1
        student["status"] = "done"
        reward = {"points": points, "comeback": comeback, "streak": student["streak"], "xp": student["xp"]}
        if comeback:
            state["self_corrected"] += 1
        if existing and existing["problem"] == problem["text"]:
            existing["status"] = "resolved"
            set_led(student["id"], "resolved")
    log_event(student, problem, body.problem_id, result, previous)
    publish()
    return {**result, "reward": reward, "xp": student["xp"], "streak": student["streak"]}

async def read_capture_body(request: Request) -> bytes:
    """Stops reading at the size limit, since Content-Length can be absent or false."""
    too_large = HTTPException(413, f"Image must be {MAX_CAPTURE_BYTES // (1024 * 1024)} MB or smaller")
    declared = request.headers.get("content-length", "")
    if declared.isdigit() and int(declared) > MAX_CAPTURE_BYTES:
        raise too_large
    body = bytearray()
    async for chunk in request.stream():
        body.extend(chunk)
        if len(body) > MAX_CAPTURE_BYTES:
            raise too_large
    if not body:
        raise HTTPException(413, "Empty body. Send the raw JPEG or PNG bytes.")
    return bytes(body)

async def capture(
    request: Request, student_id: str, problem_id: str, device_id: Optional[str] = None,
    authorization: Optional[str] = Header(None),
):
    require_device_token(authorization)
    # Reject unknown ids here so a bad request never costs a Gemini call.

        raise HTTPException(404, "Unknown problem")

    image = await read_capture_body(request)
    mime = next((m for signature, m in IMAGE_SIGNATURES if image.startswith(signature)), None)
    if not mime:
        raise HTTPException(415, "Body must be a JPEG or PNG image")

    lines = await vision.transcribe(image, mime)
    if lines is None:
        raise HTTPException(503, "Could not read the photo right now. Please use typed input instead.")

    result = await handle_attempt(Attempt(student_id=student_id, problem_id=problem_id, lines=lines))

    device = state["devices"].get(device_id) if device_id else None
    if device:
        device["last_seen"] = time.time()
        if result["verdict"] == "error":
            set_led(student_id, "waiting")
        publish()
    return {**result, "lines": lines}


async def read_jpeg(request: Request) -> bytes:
    if request.headers.get("content-type", "").split(";")[0].strip().lower() != "image/jpeg":
        raise HTTPException(415, "Send the photo as image/jpeg")
    image = await read_capture_body(request)
    if not image.startswith(b"\xff\xd8\xff"):
        raise HTTPException(400, "That is not a JPEG")
    return image


async def check_photo(student_id: str, problem_id: str, request: Request, source: str) -> dict:
    """Gemini copies the page, then the algebra engine checks it like typed work."""
    if problem_id not in PROBLEMS:
        raise HTTPException(404, "Unknown problem")
    image = await read_jpeg(request)
    if not ai.gemini_ready():
        raise HTTPException(503, "Photo reading is off. Set GOOGLE_CLOUD_PROJECT to turn it on.")
    lines = await vision.transcribe(image, "image/jpeg")
    if lines is None:
        raise HTTPException(502, "Could not read the photo")
    device = device_for(student_id)
    if not lines:
        return {"verdict": "unreadable", "first_error": None, "rows": [], "nudge": None, "reward": None,
                "lines": [], "led": led_for(device) if device else "idle"}
    result = await handle_attempt(Attempt(student_id=student_id, problem_id=problem_id, lines=lines))
    alert = open_alert_for(student_id)
    if result["verdict"] == "error" and alert:
        alert["source"] = source
        set_led(student_id, "coming" if alert["status"] == "coming" else "waiting")
    publish()
    return {**result, "lines": lines, "led": led_for(device) if device else "idle"}

def informer_rows(dataset: str) -> List[dict]:
    if dataset == "attempts":
        return list(state["events"])
    if dataset == "alerts":
        return [
            {
                "alert_id": a["id"], "created_at": iso(a["created"]), "student_ref": f"seat-{a['seat']:02d}",
                "course": a["course"], "kind": a["kind"], "source": a["source"],
                "help_requested": a["help_requested"], "misconception": a["misconception"],
                "misconception_label": a["label"], "status": a["status"],
                "teacher_rated_helpful": a["feedback"], "simulated": a["simulated"],
            }
            for a in sorted(state["alerts"].values(), key=lambda a: a["id"])
        ]
    if dataset == "misconceptions":
        counts = Counter(e["misconception"] for e in state["events"] if e["misconception"])
        students = {
            key: len({e["student_ref"] for e in state["events"] if e["misconception"] == key})
            for key in counts
        }
        return [
            {
                "misconception": key, "label": MISCONCEPTIONS[key]["label"], "attempts": count,
                "students": students[key], "reteach": MISCONCEPTIONS[key]["reteach"],
            }
            for key, count in counts.most_common()
        ]
    raise HTTPException(404, "Unknown dataset. Use attempts, alerts or misconceptions.")

@app.get("/api/stream")
async def stream():
    queue: asyncio.Queue = asyncio.Queue(maxsize=20)
    subscribers.append(queue)

    async def events():
        try:
            yield f"data: {json.dumps(snapshot())}\n\n"
            while True:
                try:
                    message = await asyncio.wait_for(queue.get(), timeout=3)
                    yield f"data: {message}\n\n"
                except asyncio.TimeoutError:
                    # A full snapshot refreshes LED timers and hardware status.
                    yield f"data: {json.dumps(snapshot())}\n\n"
        finally:
            subscribers.remove(queue)

    return StreamingResponse(
        events(), media_type="text/event-stream",
        headers={"Cache-Control": "no-cache", "X-Accel-Buffering": "no"},
    )

    "anything, and never add steps, even when the work is wrong. Use plain keyboard math "

def _parse_lines(text: str) -> List[str]:
    """Raises ValueError on anything other than a list of strings."""
    match = re.search(r"\{.*\}", text or "", re.S)
    if not match:
        raise ValueError
    lines = json.loads(match.group(0)).get("lines")
    if not isinstance(lines, list) or not all(isinstance(line, str) for line in lines):
        raise ValueError
    return [line.strip() for line in lines if line.strip()][:MAX_LINES]


async def _call_gemini(image: bytes, mime: str) -> List[str]:
    project = os.environ["GOOGLE_CLOUD_PROJECT"]
    location = os.getenv("GOOGLE_CLOUD_LOCATION", "global")
    model = os.getenv("GEMINI_MODEL", "gemini-3.8-flash")
    host = "aiplatform.googleapis.com" if location == "global" else f"{location}-aiplatform.googleapis.com"
    token = await asyncio.get_running_loop().run_in_executor(None, _google_token)
    async with httpx.AsyncClient(timeout=TIMEOUT) as client:
        response = await client.post(
            f"https://{host}/v1/projects/{project}/locations/{location}/publishers/google/models/{model}:generateContent",
            headers={"Authorization": f"Bearer {token}"},
            json={
                "contents": [{
                    "role": "user",
                    "parts": [
                        {"inlineData": {"mimeType": mime, "data": base64.b64encode(image).decode("ascii")}},
                        {"text": PROMPT},
                    ],
                }],
                "generationConfig": {"temperature": 0, "responseMimeType": "application/json"},
            },
        )
    response.raise_for_status()
    parts = response.json()["candidates"][0]["content"]["parts"]
    return _parse_lines("".join(p.get("text", "") for p in parts))

def request(url, data=None, headers=None, timeout=30):
    """Returns (status, body text). HTTP error statuses are returned, not raised."""
    req = urllib.request.Request(url, data=data, headers=headers or {}, method="POST" if data is not None else "GET")
    try:
        with urllib.request.urlopen(req, timeout=timeout) as response:
            return response.status, response.read().decode("utf-8", "replace")
    except urllib.error.HTTPError as error:
        return error.code, error.read().decode("utf-8", "replace")

                        help="device token; defaults to $TEACHIFY_DEVICE_TOKEN")
    parser.add_argument("--poll-seconds", type=float, default=30,
                        help="how long to follow the light after uploading; 0 to skip")
    args = parser.parse_args()

    with open(args.image, "rb") as f:
        image = f.read()
    if image[:2] != b"\xff\xd8":
        sys.exit(f"{args.image} is not a JPEG")

    device = urllib.parse.quote(args.device, safe="")
    try:
        status, body = request(f"{server}/api/capture/{device}", data=image, headers={
            "Content-Type": "image/jpeg", "X-Device-Token": args.token,
        })
        print(f"upload: {len(image)} bytes, HTTP {status}\n{body}")
        if not 200 <= status < 300:
            return 1

        deadline = time.monotonic() + args.poll_seconds
        while time.monotonic() < deadline:

                if current != led:
                    led = current
                    print(f"light: {led}")
            else:
                print(f"poll: HTTP {status}")
            time.sleep(1)
    except (urllib.error.URLError, OSError) as error:
        sys.exit(f"could not reach {server}: {error}")
    return 0

Press Enter to press the button. Ctrl-C to quit.
  python hardware/sim_node.py --server http://localhost:8080

import argparse
import json
import threading
import time
import urllib.request


def call(url, body=None):
    data = json.dumps(body).encode() if body is not None else None
    request = urllib.request.Request(url, data=data, headers={"Content-Type": "application/json"})
    with urllib.request.urlopen(request, timeout=5) as response:
        return json.load(response)


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--server", default="http://localhost:8080")
    parser.add_argument("--device", default="desk-07")
    parser.add_argument("--press-once", action="store_true", help="Press once, then report the LED and exit")
    args = parser.parse_args()
    base = f"{args.server.rstrip('/')}/api/device/{args.device}"

    if args.press_once:
        print("LED:", call(f"{base}/press", {"source": "hardware"})["led"])
        return

    def poll():
        last = None
        while True:
            try:
                led = call(f"{base}?poll=true")["led"]
                if led != last:
                    print(f"LED -> {led}", flush=True)
                    last = led
            except OSError as error:
                print(f"Poll failed: {error}", flush=True)
            time.sleep(1)

    threading.Thread(target=poll, daemon=True).start()
    print("Virtual node running. Press Enter to press the button.")
    try:
        while True:
            input()
            call(f"{base}/press", {"source": "hardware"})

bool openRequest(HTTPClient &http, WiFiClientSecure &secure, WiFiClient &plain,

bool parseLed(const String &body, LedState &out) {

  if (key < 0) return false;

void pollOnce() {
  // Skip this round rather than queue behind an upload.
  if (xSemaphoreTake(netLock, 0) != pdTRUE) return;

    WiFiClientSecure secure;
    WiFiClient plain;
    HTTPClient http;
    String url = String(SERVER_URL) + "/api/device/" + DEVICE_ID + "?poll=true";
    if (openRequest(http, secure, plain, url, POLL_TIMEOUT_MS)) {
      int code = http.GET();
      if (code >= 200 && code < 300) {
        LedState next;
        if (parseLed(http.getString(), next)) ledState = next;
      }
      http.end();
    }
  }
  xSemaphoreGive(netLock);
}

// HTTPClient blocks through the TLS handshake, so polling runs in its own task
// to keep loop() free for the button, the ring and the Wi-Fi check.
void pollTask(void *) {
  for (;;) {
    unsigned long started = millis();
    if (WiFi.status() == WL_CONNECTED) pollOnce();
    unsigned long elapsed = millis() - started;
    vTaskDelay(pdMS_TO_TICKS(elapsed < POLL_MS ? POLL_MS - elapsed : 10));
  }
}

void maintainWifi() {
  bool online = WiFi.status() == WL_CONNECTED;
  if (online != wasOnline) {
    wasOnline = online;
    if (online) Serial.println(WiFi.localIP());
    else Serial.println("Wi-Fi down");
  }
  if (online || millis() - lastWifiAttempt < WIFI_RETRY_MS) return;
  lastWifiAttempt = millis();
  WiFi.disconnect();
  WiFi.begin(WIFI_SSID, WIFI_PASS);
}

  WiFiClient plain;
